## Постановка

Вариант 20 из сборника ИКБО-24-25, страница 44. Вход — файл, заданный параметром командной строки, выход — YAML в стандартном выводе.

## Лексика

Числа соответствуют выражению [+-]?\d+\.\d+, имена содержат заглавные латинские буквы. Лексер отличает десятичную точку числа от точки-разделителя элемента массива. Ошибки содержат строку и столбец.

## Синтаксис

Массивы заключаются в фигурные скобки и могут быть вложены. За каждым элементом нужна точка. var объявляет константу на этапе трансляции, ^[ИМЯ] обращается к ранее объявленной константе. Повторное объявление и ссылка на ещё неизвестное имя считаются ошибкой.

## Выход

Одно значение верхнего уровня становится корнем YAML, несколько — последовательностью, только объявления дают null. Значения хранятся в Decimal и печатаются без потери точности. Ошибка синтаксиса оставляет stdout пустым и даёт код 1.

## Проверка

Области применения — резервирование запасов склада и параметры климатической системы. Тесты независимо разбирают результат через PyYAML и проверяют вложенность, отрицательные значения и ошибочные конструкции.

## Воспроизведение

Исходники находятся в src, тесты — в tests. Команды выполняются
из корня репозитория. Зависимости устанавливаются командой
`python -m pip install -r requirements.txt`. Тесты можно запустить
через run.bat в Windows или через ./run.sh в Linux.

```text
python -m src.translator --input examples/warehouse.cfg
python -m src.translator --input examples/climate.cfg
python -m unittest discover -s tests -v
```
